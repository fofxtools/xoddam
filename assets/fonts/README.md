# Fonts

- `Fredoka.ttf` - Fredoka (variable font) by The Fredoka Project Authors, SIL Open Font License 1.1 (`OFL.txt`).
  https://fonts.google.com/specimen/Fredoka
- `fredoka_bold.tres` - the same font at weight 600 (semi-bold). It is the project's default font
  (`gui/theme/custom_font` in `project.godot`), so every label and button uses it unless set otherwise.
